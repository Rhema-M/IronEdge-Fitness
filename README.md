# 🏋🏾‍♂️ IronEdge Fitness

A modern, responsive fitness landing page built with HTML, CSS, and JavaScript.

The project showcases a professional business landing page, responsive layouts, interactive user interface components, and clean frontend development practices.

## Features

- Responsive mobile-first design
- Modern navigation with mobile menu
- Full-screen hero section with call-to-action
- About section
- Services section
- Client testimonials
- Contact form with validation
- Smooth scrolling navigation
- Scroll reveal animations
- Professional CSS architecture
